# TI-68k para iPad

Esta interfaz adapta el emulador TI-68k de TI-Planet a Safari en iPad y teléfono: usa toda la anchura disponible, bloquea el desplazamiento mientras se pulsa una tecla y ofrece un teclado rápido para cálculos numéricos en vertical. Para el teclado completo, gire el teléfono a horizontal. Las ROM V200 usan la skin Voyage 200 incluida.

## Uso

1. Publique esta carpeta como un sitio estático HTTPS (GitHub Pages, Netlify, Cloudflare Pages, etc.).
2. Abra la URL con Safari en el iPad y use **Compartir → Añadir a pantalla de inicio**.
3. La ROM PedroM se carga desde el proyecto original. Para un sistema operativo de TI, cargue únicamente una imagen que esté autorizado a usar.

La página obtiene el motor y los recursos desde `https://tiplanet.org/emu68k_fork/`, por lo que necesita conexión a Internet. El motor original declara licencia GPL-2.0-or-later; mantenga los avisos de copyright y distribuya el código fuente correspondiente si decide redistribuir una copia del motor.
